# 羽约 · CUHKSZ 羽毛球预约助手

使用当前已登录的学校账号，从羽毛球日历页开始，定时预约 **一个场地、一个整点小时**。同一份扩展同时用于 Chrome 和 Edge。

**v1.1.0 恢复调试功能：只填表测试、10 秒倒计时演练、分步骤耗时、页面结构导出。默认勾选只填表；正式预约需要主动取消勾选。**

## 安装

1. 从 [Releases](https://github.com/ThreadEater/cuhksz-court-booker/releases) 下载 `Court-1.1.0.zip` 并解压到固定文件夹。也可以下载仓库源码。
2. Chrome 打开 `chrome://extensions`；Edge 打开 `edge://extensions`。
3. 开启「开发者模式」，点击 Chrome 的「加载已解压的扩展程序」或 Edge 的「加载解压缩的扩展」，选择含 `manifest.json` 的 **extension** 文件夹。
4. 在浏览器扩展菜单中固定「羽约」。Chrome 和 Edge 不需要不同的安装包。

图文步骤见 [Chrome / Edge 合并教程](docs/使用指南.md) 或 [PDF 教程](docs/Court-Guide.pdf)。更新时先处理正在执行或待查的任务，再替换文件、重新加载扩展并刷新学校页面。

## 21:58 准备，22:00 执行

1. 自行登录 [学校预约系统](https://booking.cuhk.edu.cn/index)，依次进入「运动场地 → 羽毛球场 → 预订」，停在日历页。
2. 打开扩展，填写**打球日期**、开始时间、联系电话、主题、参与人数和用途说明。
3. 检查显示的北京时间。插件按打球日期前两天的 **22:00** 计算放号；若已过该时间，点击后立即执行。
4. 正式预约：取消「只填表，停在提交前」，点击「确认自动提交一个场地」。确认状态已安排且准备完成。
5. 保持日历标签页可见、电脑唤醒、网络正常。弹窗可以关闭。最终以学校订单为准。

场地优先级：`6 → 4 / 5 / 7 → 11 / 12 / 13 / 14 → 3 / 8 → 9 / 10 → 1 / 2`。

## 调试功能

| 功能 | 用途 | 会提交吗 |
| --- | --- | --- |
| 只填表，停在提交前 | 按正常放号时间运行选场、填表和回读校验 | 不会 |
| 10 秒倒计时演练 | 从现在起 10 秒后运行同一流程；应选择已开放的未来时段 | 不会，后台强制测试模式 |
| 耗时记录 | 查看触发延迟、刷新、网络周期、打开表单、填写、总耗时、尝试轮数和换场次数 | 仅显示 |
| 页面检查 → 导出页面结构 | 排查学校页面结构变化 | 仅导出本地 JSON |

演练不会提前开放学校场地。填完后请手动关闭学校表单，保持日历可用。测试按钮不是模拟点击提交：后台在生成提交许可之前就结束任务。

## 重试与防重复提交

- 放号前准备日期、身份、时间列和加载监测；到点刷新。日期切换已发起查询时复用查询，避免额外刷新。
- 学校放号或权限开放延迟、刷新失败、打开表单超时，会在有限窗口内重试。优先尝试当前可用的下一场地；遵守服务端 `Retry-After`，登录失效和配额不足停止。
- 提交前保存持久化标记，每次尝试使用独立 ID。并发消息、重复唤醒和扩展后台重启不会直接获得第二次提交许可。
- **只有当前这一次提交的新弹窗明确说场地被其他人预订，才释放该次提交锁、排除该场地并换场。** 普通失败、超时、断网、查不到订单均不算明确拒绝。
- 结果不明只查订单；仍不能唯一确认时显示「结果待人工核验」。先到学校「我的预订」核实，再点击「我已核对学校订单，结束待查任务」。这不会取消学校订单。
- 这些保护限于同一扩展存储中的任务；不要在多个浏览器、浏览器配置或插件副本中同时预约同一账号。

学校服务器负载、网络延迟、系统休眠和其他用户竞争都会影响结果。插件不能保证抢到，也不绕过配额、验证码或学校预约权限。定时使用本机时间，请保持系统时间正确。

## 数据和权限

扩展只申请 `storage`、`alarms`、`scripting` 和 `https://booking.cuhk.edu.cn/*`。没有外部统计或上传服务器，不存储登录密码，不维护账号池，不自动刷新配额。

联系方式、主题、用途和最近任务保存在当前浏览器的 `chrome.storage.local`，正式预约时填写到学校表单。调试导出不读取输入框值、Cookie 或密码；包含元素 ID、类名、位置、日期和场地标签，分享前仍应自行检查。详细说明见 [隐私与问题反馈](docs/隐私与反馈.md)。

## 开发与验证

无需 npm 依赖。Node.js 22 或更新版本：

```sh
npm test
```

测试使用本地虚拟时钟、Chrome API 替身与页面夹具，不登录学校、不提交真实订单。覆盖倒计时、延迟放号、换场、提交锁、测试模式、旧任务迁移和诊断导出等行为；不代表当前学校页面的实时兼容性认证。

打包需 Python 3（仅标准库）：

```sh
python scripts/package.py
```

输出 `dist/Court-1.1.0.zip`，Chrome / Edge 共用。`extension/` 是运行代码，`tests/` 是无网络回归测试，`docs/` 是合并教程。

发布前请运行测试并检查包内容。不要把个人账号数据、浏览器配置、真实表单截图或原始日志提交到仓库。
