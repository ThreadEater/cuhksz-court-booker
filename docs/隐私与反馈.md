# 隐私与问题反馈

扩展无统计服务、无远程代码、无第三方上传接口。只在学校预约域名运行，复用当前账号会话。

本地保存：联系电话、主题、用途、人数、最近任务的日期和时段、登录姓名、运行事件、提交标记和订单核验结果。浏览器本地存储不是密码保险箱，使用共享电脑时应注意浏览器配置的访问权限。扩展不保存登录密码；卸载扩展会移除其本地扩展存储，不会取消学校订单或退出学校账号。

页面结构导出包含：元素标签、ID、类名、角色、矩形位置、日期、资源编号，以及白名单内的时间和场地标签。不包含输入框值、完整页面 HTML、Cookie 或浏览器登录凭据。它仍可能包含学校内部的资源标识，请在分享前检查。

提交问题时请附：插件版本、Chrome/Edge 版本、只填表还是正式预约、出错阶段、脱敏后的错误文字和耗时。不要附密码、Token、Cookie、个人联系方式、真实订单详情、账号池数据库或浏览器用户目录。

如涉及重复提交或账号身份核验问题，先停止新任务并到学校核对订单。不要公开贴敏感诊断；可先在 Issue 中仅描述现象。
